L’essentiel, à portée de main

De la place pour tout.
Des outils pour chaque jour.

Des dossiers de votre téléphone aux fichiers de votre serveur, Bonobo rassemble les outils utiles dans une interface Material 3.

01 / FICHIERS

Tout bien organisé

Copiez, déplacez et renommez vos fichiers. Créez des dossiers, sélectionnez plusieurs éléments et choisissez le tri qui vous convient.

02 / PROTECTION

Vos fichiers sensibles

Protégez vos fichiers par mot de passe grâce au chiffrement. La corbeille intégrée permet de retrouver les éléments qui y ont été placés.

03 / MULTIMÉDIA

Une pause pour vos médias

Parcourez vos photos et profitez des lecteurs audio et vidéo intégrés. La lecture dépend du format et des codecs pris en charge par votre appareil.

04 / CONNEXIONS

Au-delà du téléphone

Accédez à votre serveur FTP, votre NAS ou votre seedbox compatible. Importez aussi vos configurations de serveurs FileZilla.

05 / STOCKAGE

Un peu d’ordre

Visualisez l’espace utilisé et repérez les fichiers temporaires, les journaux et les dossiers vides avec les outils de nettoyage.

06 / APPLICATIONS

Vos applis sous la main

Consultez les applications installées, sauvegardez leurs APK et lancez leur désinstallation depuis le gestionnaire intégré.

Votre cloud, dans votre explorateur

Google Drive, directement dans Bonobo.

Connectez le compte Google de votre choix pour parcourir vos dossiers existants, télécharger vos fichiers, envoyer ceux de votre téléphone, créer des dossiers et supprimer des éléments après confirmation.

La connexion est facultative. Bonobo demande l’accès complet à Drive pour gérer vos fichiers existants ; les échanges passent directement de votre appareil aux services de Google. Les téléchargements restent sur votre téléphone jusqu’à leur suppression. La suppression dans Drive est définitive dans cette version.

Comment installer Bonobo sur Android ?

Depuis votre téléphone, ouvrez la page de téléchargement GitHub et récupérez le fichier APK dans « Assets ». Ouvrez ce fichier, puis suivez les indications d’Android. Si nécessaire, autorisez temporairement votre navigateur à installer cette application, puis retirez cette autorisation après l’installation.

L’application est-elle gratuite ?

Oui. Bonobo Explorateur est un projet libre distribué sous licence GPL v3. Son code est disponible dans le dépôt GitHub.

Où suivre les nouveautés ?

La liste des versions permet de retrouver les publications et les fichiers proposés au téléchargement. Les fonctionnalités peuvent varier selon la version installée.

Comment signaler un problème ou proposer une idée ?

Ouvrez un ticket dans la rubrique Issues du projet. Pour un problème, indiquez votre modèle de téléphone, votre version d’Android et les étapes pour le reproduire. N’ajoutez pas de mots de passe ni de fichiers personnels.

Confidentialité de l’application et du site

Pour les fichiers, les connexions cloud et Google Drive, consultez la politique de confidentialité de Bonobo Files Explorateur.

Cette page n’intègre ni publicité, ni outil d’analyse d’audience, ni formulaire. Elle ne dépose pas de cookies par son propre code.
